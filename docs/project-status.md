### CI fixes applied since scaffold was first written
- Pinned `prisma` / `@prisma/client` from `^7.9.1` to `^6.16.3`. Prisma 7
  removed inline `datasource { url = env(...) }` schema syntax in favor of
  a separate `prisma.config.ts`; v6 is the stable line our schema/code
  already assumed. Revisit the v7 migration deliberately later, not as a
  side effect of `npm install` picking up a new major version.
- `src/app/layout.tsx` used Next 16's generated `LayoutProps<"/">` type,
  which only exists after `.next/types` is generated by `next build`/`dev`.
  CI runs `tsc --noEmit` before `build`, so this failed typecheck. Replaced
  with a plain `{ children: React.ReactNode }` prop type.
- `src/app/login/page.tsx` read `searchParams` synchronously. Next 15+
  App Router passes `searchParams` as a `Promise`. This wasn't a typecheck
  error (params were loosely typed) but was a real bug: `callbackUrl` would
  always have been `undefined`, silently sending every login to `/app`
  instead of back to the originally requested page. Now `await`ed correctly.
